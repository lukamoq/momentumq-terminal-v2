# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security issue or vulnerability in this repository, please do not disclose it publicly on GitHub issues.

Instead, please send an email to security@momentumq.com or contact the maintainers directly. We will review and address valid security reports promptly.
